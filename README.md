# 이거 뭐라고 하지 (whats-it-called)

기능은 아는데 이름을 모를 때 찾아보는 UI/UX·개발 용어 사전입니다.
"누르면 슬라이더가 떠서 그대로 끌어 조절하는 거" 같은 설명으로 검색하면 **팝업 슬라이더**, **스크러빙**, **누르고-끌고-떼기** 같은 이름이 나옵니다.

- 용어 169개를 16개 카테고리로 묶어 두었습니다 (마우스 동작, 터치 제스처, 입력 컨트롤, 피드백, 창·오버레이, 레이아웃, 이미지, 영상, 갤러리, 모션, 데스크톱 앱, 접근성, 성능 패턴, 네트워크, 개발 흐름·배포).
- 각 용어마다 한국어·영어 이름, 다른 이름들, 설명, 어디서 봤는지, 관련 용어가 있습니다.
- 158개는 직접 만져 볼 수 있는 예시가 붙어 있습니다.
- 검색은 이름뿐 아니라 설명과 예시 안의 말도 찾습니다.

## 보드 보기

머리말 오른쪽 **목록 / 보드** 로 바꿉니다. 보드에서는 용어 하나가 노드 하나, 카테고리가 그룹 상자, "같이 보면 좋은 말"이 선입니다 ([학습노트](https://github.com/praswna/study-note)의 보드를 본떴습니다).

- 빈 곳을 끌거나 휠로 판을 옮기고, Ctrl+휠·두 손가락으로 확대합니다. 왼쪽 카테고리를 누르면 그 상자로 갑니다.
- 선은 기본으로 고르거나 마우스를 올린 용어의 것만 보입니다 (위 막대 "선: 고른 것만 / 묶음 안 / 모두"). 멀리 축소하면 노드 글씨 대신 카테고리 이름이 크게 보입니다.
- 고른 노드와 이어진 노드가 화면 밖에 있으면 화면 가장자리에 그 이름표(스티키 핸들)가 붙어 따라옵니다. 누르면 그 노드로 갑니다.
- 노드를 누르면 이웃 용어만 밝아지고, 두 번 누르면 설명 창이 열립니다. 창이 열린 동안은 누르는 노드로 바로 바뀝니다.
- 검색하면 찾은 용어만 밝아지고 "모아 보기"로 한눈에 봅니다.
- 휴대폰에서는 머리말 없이 판이 화면 전체를 씁니다. 위 막대(카테고리 · 검색 · 목록 · ⋯)와 오른쪽 아래 확대 막대만 떠 있고, 선 보기·조작법·빌드 표시는 ⋯ 메뉴에 있습니다. "열기"는 판 위에 절반 시트로 뜹니다 (손잡이를 아래로 끌거나 빈 곳을 누르면 닫힘).
- 보기 전용입니다. 노드 자리는 `src/board/TermBoard.tsx` 의 `defaultLayout`, 선은 `src/data/terms.ts` 의 `related` 로만 정하고 화면에서는 고칠 수 없습니다.

코드는 `src/board/TermBoard.tsx`.

## 개발

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 타입 검사 + 빌드 → dist/
```

Vite + React + TypeScript. 데이터는 `src/data/terms.ts`, 예시 컴포넌트는 `src/demos/`에 있습니다.

## 용어 추가하기

`src/data/terms.ts` 에 항목을 하나 추가하면 됩니다. `demo` 키를 넣으면 `src/demos/index.tsx` 에 같은 키로 등록된 컴포넌트가 상세 화면에 붙습니다.

## 목록 썸네일

카드의 움직이는 썸네일은 예시를 실제로 조작하며 녹화해 만듭니다. 조작 순서는 `scripts/thumbs/steps/*.json` 에 있습니다.
예시를 고치거나 새로 넣었으면 순서를 적고 다시 녹화합니다 (ffmpeg, Playwright 필요).

```bash
npm run thumbs                          # 전부 (public/thumbs, src/data/thumbs.ts 갱신)
npm run thumbs -- --only lightbox,tabs  # 일부만
```

## 배포

`main` 에 푸시하면 GitHub Actions 가 빌드해서 GitHub Pages 에 올립니다 (저장소 설정 > Pages > Source 를 "GitHub Actions" 로 한 번 바꿔 두어야 합니다).
화면 오른쪽 아래에 빌드 시각과 커밋 해시가 표시됩니다.
